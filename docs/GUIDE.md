# gonote 사용법

**https://kyeongseok-go.github.io/gonote/**

## 회의 전에 한 번 (3분)

1. 폰 사파리로 위 주소를 연다
2. 공유 버튼 → **홈 화면에 추가** → 홈 화면 아이콘으로 연다
3. **설정**(오른쪽 위 톱니)에서 세 칸을 채운다 — 회의 종류(`제직회`), 장소, 서기(내 이름).
   새 회의마다 자동으로 채워진다
4. **명부**(사람 아이콘)에 참석할 분들을 넣는다. 직분을 먼저 누르고 이름을 치면 빠르다.
   **여기에 넣어 둬야 회의 중에 발언자를 한 번 눌러 지정할 수 있다**

> 시간이 없으면 4번만 해도 된다. 명부가 비어 있어도 회의록은 나온다.

## 회의 시작할 때

1. 폰 **음성 메모**로 녹음을 켠다 (이게 1순위다 — 화면이 꺼져도 안 끊긴다)
2. gonote 를 열고 **회의 시작**
3. 받아적기 화면의 **"폰으로 녹음 시작했어요"** 를 누른다
   → 이제 적는 줄마다 *녹음 몇 분 몇 초*가 붙는다. 나중에 그 지점만 들으면 된다
4. 처음이면 **회의 틀**(제직회·당회)을 눌러 안건을 깔아 둔다
5. 제목 줄을 누르면 **회의 정보**로 간다. 거기서 참석/지참/불참을 체크한다

## 회의 중에 — 적는 법

화면 아래가 입력칸이다. **종류를 고르고 → 적고 → 넣기**, 이게 전부다.

| 종류 | 언제 | 회의록에서 |
| --- | --- | --- |
| **발언** | 누가 무슨 말을 했을 때 | 안건별 기록에 "김영수 장로: …" |
| **결정** | 정해졌을 때 | **맨 위에 번호 붙어서** |
| **할 일** | 누가 뭘 맡았을 때 | **표로, 담당·기한과 함께** |
| **보고** | 숫자·사실이 보고될 때 | 안건별 기록에 |
| **메모** | 나만 보려고 | **아무 데도 안 나간다** |

**말로 적어도 된다.** 입력칸을 누르면 폰 키보드가 올라오는데, 키보드의 **마이크 버튼**을 누르고
말하면 글자로 들어간다. 받아쓰기가 끝나면 **넣기**를 누른다.

빠르게 적는 요령:

- **종류는 한 번만 고르면 유지된다.** 발언을 연달아 적을 때 매번 누르지 않아도 된다
- **말한 사람도 유지된다.** 같은 사람이 이어 말하면 그대로 두면 된다
- 할 일에 **`@김영수`** 를 붙이면 담당자가 자동으로 붙고 그 글자는 사라진다
- 안건이 바뀌면 위의 **안건 막대**에서 다음 안건을 누른다
- 급하면 일단 **발언**으로 적고 나중에 고쳐도 된다 — **줄을 누르면 그 자리에서 종류를 바꾼다**

## 회의가 끝나면

1. **회의 정보 → 폐회 기록** (폐회 시각과 걸린 시간이 회의록에 들어간다)
2. 오른쪽 위 **회의록**을 누른다
3. 셋 중에 고른다:

| 버튼 | 무엇이 나오나 | 언제 |
| --- | --- | --- |
| **회의록 공유** | 기기 공유창 → 카톡으로 바로 | 가장 빠른 길 |
| **결정·할 일만 복사** | 짧은 글 | **카톡방에는 이게 제일 읽힌다** |
| **인쇄 · PDF** | A4 문서 | 보관·제출용. 인쇄 창에서 **"PDF로 저장"** |

> 아이폰에서 PDF: **인쇄 · PDF** → 인쇄 미리보기에서 **공유 버튼** → *파일에 저장* 또는 카톡.
> 맥에서는 인쇄 창 왼쪽 아래 **PDF ▾ → PDF로 저장**.

## 알아 둘 것

- **적은 줄은 바로 저장된다.** 앱이 꺼져도, 폰이 꺼져도 남아 있다
- **네트워크가 없어도 전부 된다.** 지하 예배실에서도 쓸 수 있다
- **자료는 이 폰 안에만 있다.** 서버로 가지 않는다. 그래서 **폰을 바꾸면 회의록도 사라진다** —
  중요한 회의록은 PDF 로 저장하거나 카톡에 올려 두는 것이 지금으로선 유일한 백업이다
- **사파리 사생활 보호 창에서는 저장이 안 된다.** 일반 창에서 쓴다
- **메모는 어디에도 나가지 않는다.** 서기만 보는 자리다
- 설정에서 **발언자 이름 가리기**를 켜면 공유 글에서 이름이 직분으로 바뀐다
  (김영수 장로 → 장로). **인쇄하는 원본은 늘 실명이다**

## 자주 묻는 것

**녹음을 앱이 직접 해 주나요?**
아니요. 일부러 그렇게 뒀습니다. 아이폰은 화면이 잠기거나 다른 앱으로 넘어가면 브라우저 녹음이
끊깁니다. 1시간 회의를 거기 맡기면 회의 하나를 통째로 날립니다. **폰 기본 음성 메모가 안전합니다.**
gonote 는 그 녹음과 **시각으로 맞물려서**, 나중에 "이 결정이 녹음 23분 12초쯤" 을 알려 줍니다.

**녹음을 자동으로 받아쓰지는 않나요?**
못 합니다. 그렇게 하려면 음성을 외부 서버로 보내야 하는데(유료 API), 이 앱은 교회 회의 발언이
밖으로 나가지 않는 것을 더 중요하게 뒀습니다.

**여러 사람이 같이 적을 수 있나요?**
아니요. 서버가 없어서 한 사람(서기)이 적습니다.
