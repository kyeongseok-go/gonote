# gonote 기능 명세

> **회의 중에 받아 적고, 회의가 끝나는 순간 회의록이 완성돼 있는 앱.**
> 회의록을 "나중에 정리하는 숙제" 에서 "회의 중에 끝나는 일" 로 바꾼다.
> 결정의 근거와 바꾸지 않을 것은 `HANDOFF.md` 에 있다.

구현 현황 2026-11-01 · 배포 https://kyeongseok-go.github.io/gonote/

## 기술 결정

| 무엇 | 무엇으로 | 왜 |
| --- | --- | --- |
| 뼈대 | Vite 8 + React 19 + TypeScript + Zustand + Dexie + HashRouter + vite-plugin-pwa | godo·gosay 에서 검증된 설정을 그대로 복사했다 |
| 저장 | IndexedDB 만. 서버도 계정도 없다 | 교회 사람들의 실명과 발언이 들어간다. 서버가 없으면 샐 곳이 없다 |
| 외부 연결 | **없다.** CSP `connect-src 'self'` | 같은 이유. API 키가 필요한 설계를 고르지 않는다 |
| 쓰기 경로 | ChangeSet 하나 (`commit(cs)`), 줄 하나마다 즉시 영속화 | **회의 중에 적은 한 줄이 날아가는 것이 이 앱의 가장 큰 실패다** |
| 순수 함수 | 오늘·지금·id 를 **인자로 받는다** | 시간 모킹 없이 자정·월말을 직접 넣어 본다 |
| 문서 모델 | `buildMinutes()` 하나를 화면과 공유 글이 함께 읽는다 | 둘이 갈라지면 같은 회의의 결정이 두 문서에서 다르게 보인다 |
| PDF | 인쇄용 CSS + 브라우저 인쇄 | PDF 라이브러리를 쓰면 한글 글꼴을 번들해야 하고 줄바꿈이 깨진다 |
| 받아쓰기 | **폰 키보드의 마이크(OS 기능)** | 웹 음성 인식은 설치한 PWA 에서 없을 수 있고, 크롬은 음성을 구글 서버로 보낸다 |

## 기능

### A. 받아적기 (핵심)
- [x] A1 회의 시작 한 번으로 바로 적기 시작 — 제목·장소·참석자를 먼저 묻지 않는다
- [x] A2 대화창 모양: 기록이 위로 쌓이고 입력은 아래 고정 (카톡과 같은 모양, 엄지가 닿는 자리)
- [x] A3 줄 종류 5가지 — 발언 / 결정 / 할 일 / 보고 / 메모. 고른 종류는 다음 줄까지 유지된다
- [x] A4 말한 사람 한 번 누르면 다음 줄까지 유지 (출처: 클로바노트·Granola 는 구조 없는 입력을 택했지만, 이 앱은 받아쓰기가 없어 **구조를 사람이 주는 수밖에 없다**)
- [x] A5 엔터로 넣기(데스크톱) · 넣기 버튼(폰). 넣으면 칸이 비고 포커스가 남는다
- [x] A6 줄마다 시각 자동 기록
- [x] A7 줄을 눌러 그 자리에서 고치기 — 종류·발언자·담당·기한·표결
- [x] A8 빈 줄은 만들지 않는다 (회의 중에 두 번 누르는 일이 잦다)
- [x] A9 적은 줄은 즉시 IndexedDB 로 간다. 앱이 죽어도 한 줄도 날아가지 않는다
- [x] A10 `@이름` 으로 담당자 지정 (출처: Obsidian 회의록 템플릿의 `@owner`)

### B. 안건
- [x] B1 안건 막대에서 지금 안건을 고르면 그 뒤 줄이 거기 붙는다
- [x] B2 회의 중에 안건을 바로 만든다 (설정 화면으로 보내면 아무도 안 만든다)
- [x] B3 회의 틀 — 제직회·당회 / 부서 회의 / 행사 준비 (출처: 조사한 14개 중 7개가 "회의 전 안건이 뼈대가 된다")
- [x] B4 틀은 회의를 시작한 **직후에만** 권한다. 한 줄이라도 적으면 사라진다
- [x] B5 교단 규정의 3단 구조(개회 → 회무 처리 → 폐회)를 안건 이름으로 깐다
- [x] B6 안건을 지워도 그 줄은 '안건 밖 기록' 으로 남는다

### C. 회의록 문서
- [x] C1 머리말 — 회의 종류·이름·일시·장소·성원(재적/참석)·서기
- [x] C2 참석/지참/불참을 이름과 직분으로 (출처: 고신 규정 "직분자 실명에 '님'을 붙이지 말 것")
- [x] C3 **결정 사항을 맨 위에** 번호 매겨 — 카톡에서 "2번 말씀인데요" 로 가리킬 수 있다
- [x] C4 표결 결과(가결·부결·유안·만장일치)와 찬반 수
- [x] C5 할 일 표 — 할 일 / 담당 / 기한 / 완료
- [x] C6 안건별 기록 — 발언자와 말
- [x] C7 다음 회의, 폐회 시각, 걸린 시간
- [x] C8 **메모는 회의록에 나오지 않는다**

### D. 내보내기
- [x] D1 인쇄 · PDF — A4 인쇄용 CSS (화면 껍데기를 숨기고 쪽 넘김을 막는다)
- [x] D2 카톡용 전체 글 복사 — 마크다운·이모지 없이 평문
- [x] D3 **결정·할 일만 복사** — 카톡에 실제로 올라가는 건 이것이다
- [x] D4 기기 공유창(`navigator.share`), 없으면 복사로 떨어진다
- [x] D5 카톡에 붙는 모양 미리보기
- [x] D6 발언자 이름 가리기 — 공유 글에서만. **인쇄하는 원본은 늘 실명이다**

### E. 명부와 설정
- [x] E1 명부 — 이름과 직분. 교회 회의는 같은 사람들이 매달 모인다
- [x] E2 숨기기(지우지 않는다) — 지난 회의록의 발언자가 사라지면 안 된다
- [x] E3 새 회의에 미리 채울 값 — 회의 종류·장소·서기
- [x] E4 참석 체크 (참석/지참/불참), 성원 수 자동 계산
- [x] E5 라이트·다크·자동
- [x] E6 모두 지우기

### F. 기본
- [x] F1 설치형 PWA, 오프라인 동작
- [x] F2 회의 목록 — 날짜·참석·결정·할 일 수
- [x] F3 회의 지우기(안건·줄 함께)
- [x] F4 저장 실패 시 사용자가 닫을 때까지 남는 경고
- [x] F5 사생활 보호 창 등 저장소가 없을 때의 안내 화면

## 일부러 뺀 것

- **자동 화자 분리·자동 받아쓰기** — API 키 없이 브라우저만으로 10명 한국어 회의를 화자별로
  받아쓰는 것은 불가능하다. 할 수 있는 척하는 UI 를 만들지 않았다
- **브라우저 전체 녹음을 1순위로 두기** — iOS 는 화면이 잠기면 녹음이 끊긴다. 1시간 회의를
  여기에 맡기면 회의 하나를 통째로 날린다. 폰 기본 음성 메모가 1순위고, gonote 는
  **녹음 기준 시각**으로 맞물린다
- **실시간 공동 편집** — 서버가 필요하다. 회의록은 서기 한 사람이 쓴다
- **카톡 자동 전송** — 외부 연결 금지. 사용자가 복사해서 붙인다
- **일정·출석·재정 관리** — 용도는 회의 정리 하나다
- **회의록 자유 편집기** — 구조를 지키는 것이 이 앱의 가치다
- **JSON 백업** — 아직 안 했다. 회의 하나를 치르는 데는 필요 없고, 다음 바퀴의 첫 항목이다
